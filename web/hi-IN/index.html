छोटा और तेज़

साइज़ के लिए ऑप्टिमाइज़्ड रिलीज़ बिल्ड — LTO, स्ट्रिप्ड, panic=abort। डेस्कटॉप ऐप OS के webview का उपयोग करता है, इसलिए कोई बंडल किया गया Chromium नहीं है।

🛡️

डिज़ाइन से ही सुरक्षित

हर एक्सट्रैक्शन पाथ एक ही zip-slip गार्ड से होकर गुज़रता है। कोई भी एंट्री डेस्टिनेशन फ़ोल्डर से बाहर नहीं निकल सकती — किसी भी बनावटी ZIP, RAR या tar से नहीं।

⚙️

एक इंजन, तीन तरीके

GUI, CLI और MCP सर्वर एक ही Rust कोर के ऊपर पतले शेल हैं। ऐप जो कुछ करता है, CLI वही सटीक रूप से करता है — और स्क्रिप्ट भी कर सकती हैं।

ZIP, RAR (RAR5 और एन्क्रिप्टेड सहित), 7z, tar और कम्प्रेस्ड-tar वैरिएंट, सिंगल-स्ट्रीम gz/bz2/xz/zst/lz4 — और ISO 9660 डिस्क इमेज।

टर्मिनल और एजेंट के लिए भी बनाया गया

CLI — ziplark

किसी भी आर्काइव को लिस्ट करें, एक्सट्रैक्ट करें, बनाएँ और वेरिफ़ाई करें। स्क्रिप्टिंग के लिए हर कमांड पर --json।

ziplark list  movie.rar
ziplark extract photos.zip -o ./out
ziplark create backup.tar.zst ./src --level best
ziplark create secret.zip ./private --password hunter2
ziplark test  download.7z

MCP सर्वर — ziplark-mcp

Model Context Protocol के ज़रिए किसी भी LLM से Ziplark चलाएँ। रीड टूल हमेशा चालू रहते हैं; राइट --allow-write के पीछे गेट किए गए हैं।

{
  "mcpServers": {
    "ziplark": {
      "command": "ziplark-mcp",
      "args": ["--allow-write"]
    }
  }
}

सामान्य प्रश्न

क्या Ziplark मुफ़्त है?

हाँ — MIT के तहत मुफ़्त और ओपन सोर्स, न कोई विज्ञापन और न ही कोई टेलीमेट्री।

क्या Ziplark RAR फ़ाइलें खोल सकता है?

हाँ। Ziplark RAR और RAR5 आर्काइव एक्सट्रैक्ट करता है, जिनमें पासवर्ड से सुरक्षित आर्काइव भी शामिल हैं। यह RAR आर्काइव बनाता नहीं है — वह फ़ॉर्मैट प्रोप्राइटरी है — लेकिन उन्हें पूरी तरह पढ़ता है।

क्या यह macOS, Windows और Linux पर काम करता है?

तीनों पर। macOS एक यूनिवर्सल, नोटराइज़्ड बिल्ड के रूप में आता है; Windows एक .msi/.exe के रूप में; Linux .deb और AppImage के रूप में।

क्या यह WinRAR, 7-Zip या The Unarchiver का एक अच्छा मुफ़्त विकल्प है?

हाँ। Ziplark क्रॉस-प्लेटफ़ॉर्म, मुफ़्त और बेहद छोटा है। यह ZIP, RAR, 7z और tar पढ़ता है और ZIP (AES-256), 7z और tar बनाता है — साथ ही स्क्रिप्टिंग और ऑटोमेशन के लिए एक CLI और एक MCP सर्वर के साथ आता है। गाइड: मुफ़्त WinRAR विकल्प, Mac पर RAR खोलें, और Mac के लिए 7-Zip।

क्या यह एन्क्रिप्टेड / पासवर्ड से सुरक्षित आर्काइव को सपोर्ट करता है?

हाँ। यह AES-256 एन्क्रिप्टेड ZIP और 7z आर्काइव बनाता है, और एन्क्रिप्टेड RAR तथा 7z आर्काइव पढ़ता है।

क्या मैं इसे कमांड लाइन या स्क्रिप्ट से इस्तेमाल कर सकता हूँ?

हाँ — ziplark CLI वह सब कुछ करती है जो ऐप करता है, हर कमांड पर --json के साथ, और ziplark-mcp इसे Model Context Protocol के ज़रिए किसी भी LLM के सामने उपलब्ध कराता है।
