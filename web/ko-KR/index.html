Ziplark는 ZIP, RAR, 7z, tar, ISO를 풀고 ZIP(AES-256), 7z, tar을 만듭니다 — 단 1.4 MB의 바이너리로. 하나의 Rust 엔진, 그것을 다루는 세 가지 방법: 데스크톱 앱, 명령줄 도구, 그리고 MCP 서버.

왜 Ziplark인가

🪶

작고 빠릅니다

크기를 최적화한 릴리스 빌드 — LTO, 스트립, panic=abort. 데스크톱 앱은 OS 웹뷰를 사용하므로 Chromium이 번들되지 않습니다.

🛡️

설계부터 안전하게

모든 압축 해제 경로는 단일 zip-slip 가드를 거칩니다. 어떤 항목도 대상 폴더를 벗어날 수 없습니다 — 조작된 ZIP, RAR, tar에서도 결코.

⚙️

하나의 엔진, 세 가지 방법

GUI, CLI, MCP 서버는 하나의 Rust 코어를 감싼 얇은 껍데기입니다. 앱이 하는 일을 CLI도 똑같이 하고 — 스크립트도 마찬가지입니다.

📦

흔히 쓰는 모든 형식

ZIP, RAR(RAR5 & 암호화 포함), 7z, tar과 압축된 tar 변형들, 단일 스트림 gz/bz2/xz/zst/lz4 — 그리고 ISO 9660 디스크 이미지.

터미널과 에이전트를 위한 설계도

CLI — ziplark

어떤 압축 파일이든 목록을 보고, 풀고, 만들고, 검증하세요. 스크립팅을 위해 모든 명령에 --json을 지원합니다.

ziplark list  movie.rar
ziplark extract photos.zip -o ./out
ziplark create backup.tar.zst ./src --level best
ziplark create secret.zip ./private --password hunter2
ziplark test  download.7z

MCP 서버 — ziplark-mcp

Model Context Protocol을 통해 어떤 LLM에서든 Ziplark를 다루세요. 읽기 도구는 항상 켜져 있고, 쓰기는 --allow-write 뒤에서 통제됩니다.

{
  "mcpServers": {
    "ziplark": {
      "command": "ziplark-mcp",
      "args": ["--allow-write"]
    }
  }
}

FAQ

Ziplark는 무료인가요?

네 — MIT 라이선스의 무료 오픈소스이며, 광고도 없고 텔레메트리도 없습니다.

Ziplark로 RAR 파일을 열 수 있나요?

네. Ziplark는 암호로 보호된 것을 포함해 RAR 및 RAR5 압축 파일을 풉니다. RAR 압축 파일을 만들지는 않습니다 — 그 형식은 독점 형식입니다 — 하지만 완전하게 읽습니다.

macOS, Windows, Linux에서 동작하나요?

세 가지 모두요. macOS는 유니버설 공증 빌드로, Windows는 .msi/.exe로, Linux는 .deb과 AppImage로 제공됩니다.

WinRAR, 7-Zip, The Unarchiver의 좋은 무료 대안인가요?

네. Ziplark는 크로스플랫폼이고 무료이며 아주 가볍습니다. ZIP, RAR, 7z, tar을 읽고 ZIP(AES-256), 7z, tar을 만듭니다 — 게다가 스크립팅과 자동화를 위한 CLI와 MCP 서버도 함께 제공합니다. 가이드: 무료 WinRAR 대안, 맥에서 RAR 열기, 맥용 7-Zip.

암호화된 / 암호로 보호된 압축 파일을 지원하나요?

네. AES-256으로 암호화된 ZIP 및 7z 압축 파일을 만들고, 암호화된 RAR 및 7z 압축 파일을 읽습니다.

명령줄이나 스크립트에서 사용할 수 있나요?

네 — ziplark CLI는 앱이 하는 모든 것을 하며, 모든 명령에 --json을 지원합니다. 그리고 ziplark-mcp는 Model Context Protocol을 통해 어떤 LLM에도 이를 노출합니다.
