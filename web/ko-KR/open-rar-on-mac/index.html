Mac에서 RAR 파일
여는 법 — 무료

macOS는 .rar 파일을 자체적으로 열지 못합니다 — 내장된 압축 유틸리티는 ZIP과 tar만 처리하니까요. Ziplark는 드래그 앤 드롭으로 RAR과 RAR5를 (암호로 보호된 것까지) 푸는 무료 오픈소스 앱입니다.

macOS용 다운로드 ★ GitHub에서 Star

또는 brew install --cask zhitongblog/tap/ziplark

세 단계로 RAR 열기

Ziplark를 설치하세요. macOS 빌드를 다운로드하거나 (유니버설, 공증됨) brew install --cask zhitongblog/tap/ziplark를 실행하세요.

RAR을 여세요. .rar 파일을 더블클릭하거나, Ziplark 창으로 끌어다 놓아 안에 든 것을 모두 미리 보세요.

압축을 푸세요. 대상을 고르고 풀기를 클릭하세요. 보호되어 있다면 먼저 암호를 입력하세요 — RAR5와 암호화된 압축 파일을 지원합니다.

The Unarchiver는 풀기만 합니다. Ziplark는 압축 파일을 풀고 만들기까지 하며, CLI + MCP 서버를 제공하고, 완전한 오픈소스입니다.

분할 압축(part1.rar, .r00)과 손상된 압축 파일

RAR에서 실제로 사람들이 막히는 건 이 두 가지이고, 둘 다 직접 방법을 찾을 필요가 없습니다.

여러 조각으로 나뉜 세트. 세트의 아무 파일이나 열면 됩니다 — movie.part03.rar이나 예전 방식의 movie.r01. Ziplark가 첫 조각을 직접 찾아 세트 전체를 풉니다. 조각을 넘나드는 파일은 하나로 되돌아가므로 미리 합칠 필요가 없습니다.

조각 하나가 빠졌을 때. Ziplark는 다음에 필요한 파일 이름(예: movie.part04.rar)을 알려줍니다. “예기치 않은 압축 파일의 끝” 같은 메시지로 끝나지 않고, 지금 가진 조각에 담긴 내용을 모두 풀겠냐고 제안합니다.

다운로드가 손상됐을 때. “읽을 수 있는 것만 추출”을 선택하면 온전한 파일은 모두 나오고, 어떤 파일이 실패했고 어떤 것이 불완전한지 목록으로 알려줍니다. 추출하지 않고 손상 내역만 보려면 먼저 검사하세요.

자동 압축 해제 .exe, 내용뿐 아니라 파일 이름까지 암호화된 압축 파일, 솔리드 압축 파일도 같은 방식으로 처리합니다. 권한·타임스탬프·심볼릭 링크가 추출 후에도 유지되므로, 꺼낸 앱이나 소스 트리가 그대로 동작합니다.

Mac에서 RAR 열기 — FAQ

추가 소프트웨어 없이 macOS에서 RAR 파일을 열 수 있나요?

아니요. 내장된 압축 유틸리티는 ZIP과 tar은 처리하지만 RAR은 처리하지 못합니다. .rar과 .rar5 파일을 열려면 Ziplark 같은 앱이 필요합니다.

Mac에서 RAR을 여는 데 Ziplark는 무료인가요?

네 — MIT 라이선스의 무료 오픈소스이며, 체험판도 광고도 없습니다.

Apple Silicon(M1/M2/M3)에서도 실행되나요?

네. macOS 빌드는 유니버설이며 공증되어 있어, Apple Silicon과 Intel에서 네이티브로 실행됩니다.

여러 파트로 나뉜 RAR 압축 파일(.part1.rar)도 열 수 있나요?

네 — Ziplark에 첫 번째 파트를 지정하면 세트를 다시 조합해 압축을 풉니다.

분할 RAR(part1.rar)은 어떻게 여나요?

세트의 아무 파일이나 열면 됩니다. 첫 조각인 part01.rar이 아니어도 괜찮습니다. Ziplark가 첫 조각을 찾아 조각을 넘나드는 파일을 되돌리므로 미리 합칠 필요가 없습니다.

.r00 파일은 무엇인가요?

예전 방식 분할 RAR의 두 번째 조각이고, 첫 조각은 그 옆의 평범한 .rar 파일입니다. 이후 .r01, .r02로 이어집니다. 아무 조각이나 열면 나머지는 Ziplark가 알아서 처리합니다.

손상되거나 불완전한 RAR도 추출할 수 있나요?

네. “읽을 수 있는 것만 추출”은 온전한 파일을 모두 기록하고 실패하거나 불완전한 파일을 나열합니다. 조각이 빠졌다면 필요한 파일 이름을 알려줍니다.
