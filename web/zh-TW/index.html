為什麼選擇 Ziplark

🪶

小巧又快速

針對體積最佳化的 release 版本 — LTO、去除除錯符號、panic=abort。 桌面 App 使用系統內建的 webview，因此不會夾帶 Chromium。

🛡️

設計上就安全

每一條解壓路徑都會通過單一的 zip-slip 防護。任何項目都無法逃出目標資料夾 — 無論是精心構造的 ZIP、RAR 還是 tar 都一樣。

⚙️

一顆引擎，三種用法

GUI、CLI 與 MCP 伺服器都是同一顆 Rust 核心之上的輕薄外殼。 App 能做的，CLI 也做得一模一樣 — 腳本同樣辦得到。

📦

各種常見格式一網打盡

ZIP、RAR（含 RAR5 與加密檔）、7z、tar 以及各種壓縮 tar 變體、 單一串流的 gz/bz2/xz/zst/lz4 — 還有 ISO 9660 光碟映像檔。

同樣為終端機與 AI 代理打造

CLI — ziplark

列出、解壓、建立與驗證任何封存檔。每個指令都支援 --json，方便寫腳本。

ziplark list  movie.rar
ziplark extract photos.zip -o ./out
ziplark create backup.tar.zst ./src --level best
ziplark create secret.zip ./private --password hunter2
ziplark test  download.7z

MCP 伺服器 — ziplark-mcp

透過 Model Context Protocol，從任何 LLM 驅動 Ziplark。讀取工具永遠開啟； 寫入操作則受 --allow-write 保護。

{
  "mcpServers": {
    "ziplark": {
      "command": "ziplark-mcp",
      "args": ["--allow-write"]
    }
  }
}

常見問題

Ziplark 是免費的嗎？

是的 — 採用 MIT 授權，免費且開源，沒有廣告、沒有遙測。

Ziplark 可以開啟 RAR 檔案嗎？

可以。Ziplark 能解壓 RAR 與 RAR5 封存檔，包含有密碼保護的檔案。 它不會建立 RAR 封存檔 — 該格式是專有格式 — 但能完整讀取它們。

它能在 macOS、Windows 和 Linux 上運作嗎？

三者皆可。macOS 以通用版、已公證的形式發佈；Windows 提供 .msi/.exe；Linux 則提供 .deb 與 AppImage。

它是 WinRAR、7-Zip 或 The Unarchiver 的優秀免費替代方案嗎？

是的。Ziplark 跨平台、免費又輕巧。它能讀取 ZIP、RAR、7z 與 tar，並建立 ZIP（AES-256）、7z 與 tar — 還附帶 CLI 與 MCP 伺服器，方便寫腳本與自動化。相關指南： 免費 WinRAR 替代方案、 在 Mac 上開啟 RAR，以及 Mac 版 7-Zip。

它支援加密／有密碼保護的封存檔嗎？

支援。它能建立 AES-256 加密的 ZIP 與 7z 封存檔，並讀取加密的 RAR 與 7z 封存檔。

我可以從命令列或腳本使用它嗎？

可以 — ziplark CLI 能做到 App 所有的功能，每個指令都支援 --json，而 ziplark-mcp 則透過 Model Context Protocol 將它開放給任何 LLM。
