如何在 Mac 上開啟
RAR 檔案 — 免費

macOS 本身無法開啟 .rar 檔案 — 內建的封存工具程式只支援 ZIP 與 tar。Ziplark 是一款免費、開源的 App，只要拖放就能解壓 RAR 與 RAR5（包含有密碼保護的檔案）。

下載 macOS 版 ★ 在 GitHub 上按 Star

或使用 brew install --cask zhitongblog/tap/ziplark

三步驟開啟 RAR

安裝 Ziplark。 下載 macOS 版本 （通用版、已公證），或執行 brew install --cask zhitongblog/tap/ziplark。

開啟 RAR。 雙擊 .rar 檔案，或將它拖放 到 Ziplark 視窗上，即可預覽裡面的所有內容。

解壓。 選擇目標位置並點擊解壓。如果檔案有密碼保護， 請先輸入密碼 — 支援 RAR5 與加密封存檔。

在 Mac 上開啟 RAR — 常見問題

macOS 不安裝額外軟體就能開啟 RAR 檔案嗎？

不能。內建的封存工具程式支援 ZIP 與 tar，但不支援 RAR。你需要像 Ziplark 這樣的 App 才能開啟 .rar 與 .rar5 檔案。

用 Ziplark 在 Mac 上開啟 RAR 是免費的嗎？

是的 — 採用 MIT 授權，免費且開源，沒有試用期、沒有廣告。

它能在 Apple Silicon（M1/M2/M3）上運作嗎？

可以。macOS 版本為通用版且已公證，因此能在 Apple Silicon 與 Intel 上原生執行。

它能開啟多分割的 RAR 封存檔（.part1.rar）嗎？

可以 — 讓 Ziplark 指向第一個分割檔，它就會重新組合整組檔案來解壓。
