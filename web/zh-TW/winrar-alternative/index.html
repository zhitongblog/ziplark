Ziplark 不會建立 RAR 封存檔 — 該壓縮格式是專有格式 — 但它能完整解壓 RAR 與 RAR5，並改為建立 ZIP、7z 與 tar。

為什麼要換掉 WinRAR？

WinRAR 是個不錯的解壓工具，但有三件事讓人開始尋找替代方案：

  • 永無止境的試用。40 天過後，WinRAR 仍可繼續使用，但每次開啟都會跳出 購買授權的提醒。
  • 其實只有 Windows 能用。在 macOS 與 Linux 上，WinRAR 只是一個純 命令列的執行檔 — 沒有圖形化 App。
  • 封閉原始碼。你看不到它到底做了什麼，也難以乾淨地整合進現代 自動化腳本。

Ziplark 在這三點上完全相反：採用 MIT 授權、免費且開源，在每個系統上都有真正的桌面 App， 還有一顆小巧的 Rust 引擎，你同樣能從命令列或透過 MCP 由 AI 代理來驅動。

如何在 30 秒內從 WinRAR 轉換過來

  1. 下載 Ziplark 適合你系統的版本（或在 macOS 上： brew install --cask zhitongblog/tap/ziplark）。
  2. 雙擊任何 .rar 檔案，或將它拖放到 Ziplark 視窗上。
  3. 選擇解壓位置 — 完成。要建立新的封存檔，切換到 建立， 把檔案拖進來，然後選擇 ZIP（AES-256）、7z 或 tar。

偏好使用終端機？ziplark extract movie.rar -o ./out 也能做到同樣的事， 而 ziplark --help 會列出其餘指令。

WinRAR 替代方案 — 常見問題

真的有免費的 WinRAR 替代方案嗎？

有 — Ziplark 採用 MIT 授權，免費且開源，沒有試用期、沒有提示視窗、沒有廣告。 它能開啟 RAR/RAR5，並建立 ZIP、7z 與 tar。

它能開啟有密碼保護的 RAR 檔案嗎？

可以。Ziplark 能讀取加密的 RAR 與 RAR5 封存檔 — 只要在提示時輸入密碼即可。

為什麼它無法建立 .rar 檔案？

RAR 壓縮格式是專有格式，因此沒有任何免費工具能合法地建立它。Ziplark 會建立 ZIP（AES-256）、7z 與 tar，這些都是開放格式，功能同樣強大。

有 Mac 版的 WinRAR 嗎？

沒有 App — WinRAR 在 macOS 上只提供 CLI。Ziplark 是一款免費的圖形化 WinRAR 替代方案，適用於 macOS、Windows 與 Linux。另可參閱 如何在 Mac 上開啟 RAR。
