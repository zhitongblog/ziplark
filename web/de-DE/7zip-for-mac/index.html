Warum Leute nach „7-Zip für Mac“ suchen

7-Zip ist der Standard-Archivierer unter Windows, also suchen Leute beim Umstieg auf einen Mac nach demselben Programm — und stoßen an eine Wand: Das offizielle 7-Zip hat keine macOS-App. Die üblichen Behelfslösungen sind die alternde p7zip-Kommandozeile oder ein kostenpflichtiges App-Store-Tool.

Ziplark gibt dir genau den Teil, den du eigentlich wolltest: eine kleine, native Mac-App, die .7z mit AES-256 liest und schreibt, auch ZIP, RAR (entpacken), tar und ISO verarbeitet und — falls dir 7-Zips Skriptfähigkeit gefiel — eine echte CLI plus einen MCP-Server für KI-Agenten mitbringt.

Eine .7z auf dem Mac erstellen

Öffne in der App Erstellen, ziehe deine Dateien hinein, wähle 7z und eine Kompressionsstufe, füge für AES-256 ein Passwort hinzu und speichere. Über das Terminal:

ziplark create archive.7z ./folder --level best
ziplark create secret.7z ./folder --password hunter2

7-Zip auf dem Mac — FAQ

Gibt es ein offizielles 7-Zip für macOS?

Nein — nur den p7zip-Kommandozeilen-Port. Ziplark ist eine kostenlose, quelloffene App, die .7z auf macOS mit einer GUI öffnet und erstellt.

Wie entpacke ich eine .7z-Datei auf dem Mac?

Installiere Ziplark, doppelklicke dann auf die .7z oder ziehe sie ins Fenster und wähle das Zielverzeichnis.

Kann ich verschlüsselte 7z-Archive erstellen?

Ja — Ziplark schreibt AES-256-verschlüsselte .7z- (und ZIP-)Archive auf jedem Betriebssystem.

Funktioniert es auf Apple Silicon?

Ja, der macOS-Build ist universal und für Apple Silicon und Intel notarisiert.
