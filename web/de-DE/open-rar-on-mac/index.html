So öffnest du RAR-Dateien
auf dem Mac — kostenlos

macOS öffnet .rar-Dateien nicht von selbst — das integrierte Archivierungsprogramm beherrscht nur ZIP und tar. Ziplark ist eine kostenlose, quelloffene App, die RAR und RAR5 (auch passwortgeschützte) per Drag-and-drop entpackt.

Für macOS herunterladen ★ Auf GitHub bewerten

oder brew install --cask zhitongblog/tap/ziplark

Eine RAR in drei Schritten öffnen

Ziplark installieren. Lade den macOS-Build herunter (universal, notarisiert) oder führe brew install --cask zhitongblog/tap/ziplark aus.

RAR öffnen. Doppelklicke auf die .rar-Datei oder ziehe sie ins Ziplark-Fenster, um alles darin vorab anzusehen.

Entpacken. Wähle ein Ziel und klicke auf Entpacken. Ist das Archiv geschützt, gib zuerst das Passwort ein — RAR5 und verschlüsselte Archive werden unterstützt.

RAR auf dem Mac öffnen — FAQ

Kann macOS RAR-Dateien ohne Zusatzsoftware öffnen?

Nein. Das integrierte Archivierungsprogramm verarbeitet ZIP und tar, aber nicht RAR. Du brauchst eine App wie Ziplark, um .rar- und .rar5-Dateien zu öffnen.

Ist Ziplark kostenlos, um RAR auf dem Mac zu öffnen?

Ja — kostenlos und quelloffen unter MIT, ohne Testphase und ohne Werbung.

Läuft es auf Apple Silicon (M1/M2/M3)?

Ja. Der macOS-Build ist universal und notarisiert, läuft also nativ auf Apple Silicon und Intel.

Kann es mehrteilige RAR-Archive (.part1.rar) öffnen?

Ja — verweise Ziplark auf den ersten Teil, und es setzt den Satz zum Entpacken wieder zusammen.
