Warum Ziplark

🪶

Klein & schnell

Größenoptimierter Release-Build — LTO, gestrippt, panic=abort. Die Desktop-App nutzt die WebView des Betriebssystems, es ist also kein Chromium gebündelt.

🛡️

Sicher von Grund auf

Jeder Entpackungspfad läuft durch einen einzigen Zip-Slip-Schutz. Kein Eintrag kann jemals aus dem Zielordner ausbrechen — auch nicht aus einem manipulierten ZIP, RAR oder tar.

⚙️

Eine Engine, drei Wege

GUI, CLI und MCP-Server sind dünne Hüllen über einem einzigen Rust-Kern. Was die App tut, tut die CLI identisch — und Skripte ebenso.

📦

Jedes gängige Format

ZIP, RAR (inkl. RAR5 & verschlüsselt), 7z, tar und die komprimierten tar-Varianten, gz/bz2/xz/zst/lz4 als Einzelstrom — und ISO-9660-Disk-Images.

Das Erstellen von RAR wird bewusst nicht unterstützt — das RAR-Kompressionsformat ist proprietär. Das Entpacken (einschließlich RAR5 und verschlüsselter Archive) funktioniert vollständig.

Auch für Terminals und Agenten gemacht

CLI — ziplark

Liste, entpacke, erstelle und prüfe jedes Archiv. --json bei jedem Befehl fürs Scripting.

ziplark list  movie.rar
ziplark extract photos.zip -o ./out
ziplark create backup.tar.zst ./src --level best
ziplark create secret.zip ./private --password hunter2
ziplark test  download.7z

MCP-Server — ziplark-mcp

Steuere Ziplark von jedem LLM über das Model Context Protocol. Lese-Tools sind immer aktiv; Schreibvorgänge sind hinter --allow-write abgesichert.

{
  "mcpServers": {
    "ziplark": {
      "command": "ziplark-mcp",
      "args": ["--allow-write"]
    }
  }
}

FAQ

Ist Ziplark kostenlos?

Ja — kostenlos und quelloffen unter der MIT-Lizenz, ohne Werbung und ohne Telemetrie.

Kann Ziplark RAR-Dateien öffnen?

Ja. Ziplark entpackt RAR- und RAR5-Archive, auch passwortgeschützte. Es erstellt keine RAR-Archive — dieses Format ist proprietär — liest sie aber vollständig.

Funktioniert es unter macOS, Windows und Linux?

Alle drei. macOS wird als universeller, notarisierter Build ausgeliefert; Windows als .msi/.exe; Linux als .deb und AppImage.

Ist es eine gute kostenlose Alternative zu WinRAR, 7-Zip oder The Unarchiver?

Ja. Ziplark ist plattformübergreifend, kostenlos und winzig. Es liest ZIP, RAR, 7z und tar und erstellt ZIP (AES-256), 7z und tar — außerdem bringt es eine CLI und einen MCP-Server für Scripting und Automatisierung mit. Anleitungen: kostenlose WinRAR-Alternative, RAR auf dem Mac öffnen und 7-Zip für Mac.

Unterstützt es verschlüsselte / passwortgeschützte Archive?

Ja. Es erstellt AES-256-verschlüsselte ZIP- und 7z-Archive und liest verschlüsselte RAR- und 7z-Archive.

Kann ich es über die Kommandozeile oder Skripte nutzen?

Ja — die ziplark-CLI kann alles, was die App kann, mit --json bei jedem Befehl, und ziplark-mcp stellt es jedem LLM über das Model Context Protocol bereit.
