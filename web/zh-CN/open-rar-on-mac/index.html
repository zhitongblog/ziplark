如何在 Mac 上
打开 RAR 文件——免费

macOS 自身无法打开 .rar 文件——自带的归档实用工具只能处理 ZIP 和 tar。Ziplark 是一款免费、开源的应用，只需拖放即可解压 RAR 和 RAR5（包括受密码保护的压缩包）。

下载 macOS 版 ★ 在 GitHub 上 Star

或 brew install --cask zhitongblog/tap/ziplark

三步打开 RAR

安装 Ziplark。下载 macOS 构建 （通用版、已公证）或运行 brew install --cask zhitongblog/tap/ziplark。

打开 RAR。双击 .rar 文件，或将它 拖到 Ziplark 窗口上，预览其中的全部内容。

解压。选择目标位置并点击解压。如果压缩包受保护， 请先输入密码——支持 RAR5 和加密压缩包。

在 Mac 上打开 RAR——常见问题

macOS 不装额外软件能打开 RAR 文件吗？

不能。自带的归档实用工具能处理 ZIP 和 tar，但不能处理 RAR。你需要像 Ziplark 这样的应用来打开 .rar 和 .rar5 文件。

用 Ziplark 在 Mac 上打开 RAR 是免费的吗？

是的——基于 MIT 免费开源，没有试用期，也没有广告。

它能在 Apple Silicon（M1/M2/M3）上运行吗？

能。macOS 构建为通用版且已公证，因此能在 Apple Silicon 和 Intel 上原生运行。

它能打开分卷 RAR 压缩包（.part1.rar）吗？

能——将 Ziplark 指向第一个分卷，它会重新组合整套文件进行解压。
