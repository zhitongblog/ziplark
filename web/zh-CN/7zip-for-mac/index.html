为什么人们搜索"Mac 版 7-Zip"

7-Zip 是 Windows 上的首选压缩工具，所以当人们转到 Mac 时会寻找同样的 工具——结果却碰壁：官方 7-Zip 没有 macOS 应用。常见的变通方法是那个 老旧的 p7zip 命令行，或者 App Store 上的付费工具。

Ziplark 给你的正是你真正想要的部分：一个小巧、原生的 Mac 应用，能读写 带 AES-256 的 .7z，同时也能处理 ZIP、RAR（解压）、tar 和 ISO——而且——如果 你喜欢 7-Zip 的可脚本化，它还附带真正的 CLI 加上供 AI 智能体使用的 MCP 服务器。

在 Mac 上创建 .7z

在应用中，打开创建，把文件拖进去，选择 7z 和一个 压缩级别，添加密码以启用 AES-256，然后保存。在终端中：

ziplark create archive.7z ./folder --level best
ziplark create secret.7z ./folder --password hunter2

Mac 上的 7-Zip——常见问题

有官方的 macOS 版 7-Zip 吗？

没有——只有 p7zip 命令行移植版。Ziplark 是一款免费、开源的应用， 能在 macOS 上用图形界面打开和创建 .7z。

如何在 Mac 上解压 .7z 文件？

安装 Ziplark，然后双击 .7z 或将它拖到窗口上，并选择 解压位置。

我能创建加密的 7z 压缩包吗？

能——Ziplark 能在每个操作系统上写入 AES-256 加密的 .7z（和 ZIP）压缩包。

它能在 Apple Silicon 上运行吗？

能，macOS 构建为通用版，并已为 Apple Silicon 和 Intel 公证。
