为什么选择 Ziplark

🪶

小巧且快速

体积优化的发布构建 — LTO、strip 精简、panic=abort。 桌面应用使用系统自带的 webview，因此不捆绑 Chromium。

🛡️

设计即安全

每一条解压路径都经由同一个 zip-slip 防护把关。任何条目 都无法逃出目标文件夹 — 无论是精心构造的 ZIP、RAR 还是 tar。

⚙️

一个引擎，三种方式

GUI、CLI 和 MCP 服务器都是同一个 Rust 内核之上的轻薄外壳。 应用能做的，CLI 也能一模一样地做到 — 脚本亦然。

📦

涵盖各种常见格式

ZIP、RAR（含 RAR5 和加密）、7z、tar 以及压缩 tar 变体、单流 gz/bz2/xz/zst/lz4 — 还有 ISO 9660 光盘镜像。

同样为终端和智能体而生

CLI — ziplark

列出、解压、创建和校验任意压缩包。每条命令都支持 --json 便于脚本调用。

ziplark list  movie.rar
ziplark extract photos.zip -o ./out
ziplark create backup.tar.zst ./src --level best
ziplark create secret.zip ./private --password hunter2
ziplark test  download.7z

MCP 服务器 — ziplark-mcp

通过 Model Context Protocol 让任意 LLM 驱动 Ziplark。读取工具 始终开启；写入操作则由 --allow-write 把关。

{
  "mcpServers": {
    "ziplark": {
      "command": "ziplark-mcp",
      "args": ["--allow-write"]
    }
  }
}

常见问题

Ziplark 是免费的吗？

是的 — 采用 MIT 许可证，免费且开源，没有广告，也没有遥测。

Ziplark 能打开 RAR 文件吗？

可以。Ziplark 能解压 RAR 和 RAR5 压缩包，包括受密码保护的压缩包。 它不会创建 RAR 压缩包 — 该格式是专有的 — 但能完整 读取它们。

它能在 macOS、Windows 和 Linux 上运行吗？

三者皆可。macOS 以通用、已公证的构建发布；Windows 提供 .msi/.exe；Linux 提供 .deb 和 AppImage。

它是 WinRAR、7-Zip 或 The Unarchiver 的优秀免费替代品吗？

是的。Ziplark 跨平台、免费且轻巧。它能读取 ZIP、RAR、7z 和 tar，并 创建 ZIP（AES-256）、7z 和 tar — 还附带 CLI 和 MCP 服务器用于 脚本和自动化。指南： 免费 WinRAR 替代品、 在 Mac 上打开 RAR 以及 Mac 版 7-Zip。

它支持加密 / 受密码保护的压缩包吗？

支持。它能创建 AES-256 加密的 ZIP 和 7z 压缩包，并读取加密的 RAR 和 7z 压缩包。

我能通过命令行或脚本使用它吗？

可以 — ziplark CLI 能完成应用的一切操作，每条命令都支持 --json，而 ziplark-mcp 则通过 Model Context Protocol 将其 暴露给任意 LLM。
