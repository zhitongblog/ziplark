Ziplark 不创建 RAR 压缩包——该压缩格式是专有的—— 但它能完整解压 RAR 和 RAR5，并改为创建 ZIP、7z 和 tar。

为什么要替换 WinRAR？

WinRAR 是个不错的解压工具，但有三件事促使人们去寻找替代品：

  • 永久试用。40 天后 WinRAR 仍能使用，但每次打开都会 弹出购买许可证的提醒。
  • 其实只支持 Windows。在 macOS 和 Linux 上，WinRAR 只是一个 裸命令行程序——没有图形应用。
  • 闭源。你无法看清它到底做了什么，也难以顺畅地 接入现代自动化流程。

Ziplark 在这三点上恰恰相反：基于 MIT 免费开源，在每个操作系统上都是 真正的桌面应用，还有一个小巧的 Rust 引擎，你也可以从命令行或通过 MCP 用 AI 智能体来驱动它。

如何在 30 秒内从 WinRAR 切换过来

  1. 为你的系统下载 Ziplark（或在 macOS 上： brew install --cask zhitongblog/tap/ziplark）。
  2. 双击任意 .rar 文件，或将它拖到 Ziplark 窗口上。
  3. 选择解压位置——完成。要创建新压缩包，切换到创建， 把文件拖进去，然后选择 ZIP（AES-256）、7z 或 tar。

喜欢用终端？ziplark extract movie.rar -o ./out 能完成同样的操作， 而 ziplark --help 会列出其余命令。

WinRAR 替代品——常见问题

有真正免费的 WinRAR 替代品吗？

有——Ziplark 基于 MIT 免费开源，没有试用期、没有弹窗骚扰、也没有广告。 它能打开 RAR/RAR5 并创建 ZIP、7z 和 tar。

它能打开受密码保护的 RAR 文件吗？

能。Ziplark 可以读取加密的 RAR 和 RAR5 压缩包——在提示时输入密码即可。

为什么它不能创建 .rar 文件？

RAR 压缩格式是专有的，因此没有免费工具能合法创建它。Ziplark 创建 ZIP（AES-256）、7z 和 tar，它们都是开放格式，能力同样强大。

有 Mac 版的 WinRAR 吗？

没有应用版——WinRAR 在 macOS 上只提供命令行。Ziplark 是一款免费的图形化 WinRAR 替代品，支持 macOS、Windows 和 Linux。另见 如何在 Mac 上打开 RAR。
