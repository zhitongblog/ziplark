Pourquoi les gens cherchent « 7-Zip pour Mac »

7-Zip est l'archiveur de référence sur Windows, alors quand on passe au Mac on cherche la même chose — et on se heurte à un mur : le 7-Zip officiel n'a pas d'application macOS. Les solutions de contournement habituelles sont la ligne de commande p7zip vieillissante ou un utilitaire payant sur l'App Store.

Ziplark vous offre ce que vous vouliez vraiment : une petite application Mac native qui lit et écrit les .7z en AES-256, gère aussi les ZIP, RAR (extraction), tar et ISO, et — si vous appréciiez la scriptabilité de 7-Zip — embarque une vraie CLI plus un serveur MCP pour les agents IA.

Créer un .7z sur Mac

Dans l'application, ouvrez Créer, glissez-y vos fichiers, choisissez 7z et un niveau de compression, ajoutez un mot de passe pour l'AES-256, puis enregistrez. Depuis le terminal :

ziplark create archive.7z ./folder --level best
ziplark create secret.7z ./folder --password hunter2

7-Zip sur Mac — FAQ

Existe-t-il un 7-Zip officiel pour macOS ?

Non — seulement le portage p7zip en ligne de commande. Ziplark est une application gratuite et open source qui ouvre et crée des .7z sur macOS avec une interface graphique.

Comment extraire un fichier .7z sur Mac ?

Installez Ziplark, puis double-cliquez sur le .7z ou glissez-le sur la fenêtre et choisissez où extraire.

Puis-je créer des archives 7z chiffrées ?

Oui — Ziplark écrit des archives .7z (et ZIP) chiffrées en AES-256 sur tous les OS.

Fonctionne-t-il sur Apple Silicon ?

Oui, la build macOS est universelle et notarisée pour Apple Silicon et Intel.
