Comment ouvrir les fichiers RAR
sur Mac — gratuit

macOS n'ouvre pas les fichiers .rar tout seul — l'utilitaire d'archive intégré ne gère que les ZIP et tar. Ziplark est une application gratuite et open source qui extrait les RAR et RAR5 (y compris celles protégées par mot de passe) par simple glisser-déposer.

Télécharger pour macOS ★ Star sur GitHub

ou brew install --cask zhitongblog/tap/ziplark

Ouvrir un RAR en trois étapes

Installez Ziplark. Téléchargez la build macOS (universelle, notarisée) ou exécutez brew install --cask zhitongblog/tap/ziplark.

Ouvrez le RAR. Double-cliquez sur le fichier .rar, ou glissez-le sur la fenêtre de Ziplark pour prévisualiser tout son contenu.

Extrayez. Choisissez une destination et cliquez sur extraire. Si elle est protégée, saisissez d'abord le mot de passe — les archives RAR5 et chiffrées sont prises en charge.

Ouvrir un RAR sur Mac — FAQ

macOS peut-il ouvrir les fichiers RAR sans logiciel supplémentaire ?

Non. L'utilitaire d'archive intégré gère les ZIP et tar, mais pas les RAR. Il vous faut une application comme Ziplark pour ouvrir les fichiers .rar et .rar5.

Ziplark est-il gratuit pour ouvrir des RAR sur Mac ?

Oui — gratuit et open source sous licence MIT, sans essai et sans publicité.

Fonctionne-t-il sur Apple Silicon (M1/M2/M3) ?

Oui. La build macOS est universelle et notarisée, donc elle tourne nativement sur Apple Silicon et Intel.

Peut-il ouvrir les archives RAR en plusieurs parties (.part1.rar) ?

Oui — indiquez à Ziplark la première partie et il réassemble l'ensemble pour l'extraire.
