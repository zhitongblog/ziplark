Privacy Policy

Last updated: November 2026

Summary: Zero Data Collection

Ziplark collects no personal data, no usage analytics, and no telemetry. Every archive operation — listing, previewing, searching, extracting, creating, modifying, and converting — runs 100% locally on your device.

1. Local-Only Processing

Files and archives you open, preview, extract, or create in Ziplark never leave your computer. Ziplark has no user accounts, no cloud sync, no advertising SDKs, and no crash-reporting or analytics services.

2. File System Permissions

Ziplark only accesses files and folders that you explicitly open, drag and drop into the window, or select through the operating system's standard file and folder dialogs ( plus the Downloads folder when extracting archives in place). File timestamps and permissions are read and restored solely to preserve archive metadata on your device.

3. Contact

If you have any questions about this Privacy Policy, please open an issue at github.com/zhitongblog/ziplark/issues.
