Ziplark は RAR アーカイブを作成しません — その圧縮形式は独自仕様のためです — が、RAR と RAR5 を完全に展開し、代わりに ZIP、7z、tar を作成します。

なぜ WinRAR を乗り換えるのか？

WinRAR は優れた展開ツールですが、3 つの理由から代替を探す人が多くいます。

  • 終わらない試用期間。40 日を過ぎても WinRAR は動作しますが、開くたびに ライセンス購入を促すリマインドが表示されます。
  • 実質 Windows 専用。macOS と Linux では、WinRAR は素のコマンドライン バイナリで、グラフィカルなアプリはありません。
  • クローズドソース。内部で何をしているか確認できず、最新の自動化に きれいに組み込むこともできません。

Ziplark はこの 3 つすべてで正反対です。MIT ライセンスの無料・オープンソースで、すべての OS で 本物のデスクトップアプリとして動き、コマンドラインからも MCP を通じて AI エージェントからも 操作できる、ひとつの小さな Rust エンジンです。

30 秒で WinRAR から乗り換える方法

  1. お使いの OS 向けに Ziplark をダウンロードします（macOS では brew install --cask zhitongblog/tap/ziplark でも可）。
  2. 任意の .rar ファイルをダブルクリックするか、Ziplark のウィンドウにドラッグします。
  3. 展開先を選べば完了です。新しくアーカイブを作るには 作成に切り替え、 ファイルをドラッグして、ZIP（AES-256）、7z、tar から選びます。

ターミナル派の方へ。ziplark extract movie.rar -o ./out で同じことができ、 ziplark --help で残りのコマンドを一覧できます。

WinRAR の代替 — よくある質問

WinRAR の本当に無料な代替はありますか？

はい — Ziplark は MIT ライセンスの無料・オープンソースで、試用期間も催促画面も広告もありません。 RAR/RAR5 を開き、ZIP、7z、tar を作成します。

パスワード保護された RAR ファイルを開けますか？

はい。Ziplark は暗号化された RAR と RAR5 アーカイブを読み込めます — 求められたらパスワードを入力するだけです。

なぜ .rar ファイルを作成できないのですか？

RAR の圧縮形式は独自仕様のため、無料のツールが合法的に作成することはできません。Ziplark は、 オープンで同等に強力な ZIP（AES-256）、7z、tar を作成します。

Mac 版の WinRAR はありますか？

アプリとしてはありません — WinRAR は macOS では CLI のみを提供します。Ziplark は macOS・Windows・Linux 向けの無料でグラフィカルな WinRAR 代替です。 Mac で RAR を開く方法もご覧ください。
