Mac で RAR ファイルを
開く方法 — 無料

macOS は単体では .rar ファイルを開けません — 内蔵のアーカイブユーティリティは ZIP と tar のみに対応します。Ziplark は、（パスワード保護されたものも含め） RAR と RAR5 をドラッグ＆ドロップで展開する、無料・オープンソースのアプリです。

3 ステップで RAR を開く

Ziplark をインストール。macOS 版をダウンロード （ユニバーサル・公証済み）するか、brew install --cask zhitongblog/tap/ziplark を実行します。

RAR を開く。.rar ファイルをダブルクリックするか、Ziplark の ウィンドウにドラッグして中身をすべてプレビューします。

展開する。展開先を選んで展開をクリックします。保護されている場合は、 先にパスワードを入力してください — RAR5 と暗号化アーカイブに対応しています。

Mac で RAR を開く — よくある質問

追加ソフトなしで macOS は RAR ファイルを開けますか？

いいえ。内蔵のアーカイブユーティリティは ZIP と tar には対応しますが、RAR には対応しません。 .rar や .rar5 ファイルを開くには、Ziplark のようなアプリが必要です。

Mac で RAR を開くのに Ziplark は無料ですか？

はい — MIT ライセンスの無料・オープンソースで、試用期間も広告もありません。

Apple Silicon（M1/M2/M3）で動作しますか？

はい。macOS ビルドはユニバーサルで公証済みのため、Apple Silicon と Intel の両方でネイティブに動作します。

分割された RAR アーカイブ（.part1.rar）を開けますか？

はい — 最初のパートを Ziplark で指定すれば、分割セットを結合して展開します。
