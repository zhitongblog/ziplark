なぜ「Mac 版 7-Zip」を検索するのか

7-Zip は Windows の定番アーカイバーなので、Mac に移行した人は同じものを探し — そして壁にぶつかります。公式の 7-Zip には macOS アプリがないのです。よくある回避策は、 古びた p7zip コマンドラインか、App Store の有料ユーティリティです。

Ziplark は、あなたが本当に欲しかった部分を提供します。AES-256 で .7z を読み書きし、 ZIP、RAR（展開）、tar、ISO にも対応する、小さくネイティブな Mac アプリです。さらに 7-Zip のスクリプト性が気に入っていた方のために、本物の CLI と、AI エージェント向けの MCP サーバーも同梱しています。

Mac で .7z を作成する

アプリで 作成を開き、ファイルをドラッグして、7z と圧縮レベルを選び、 AES-256 用のパスワードを付けて保存します。ターミナルからは：

ziplark create archive.7z ./folder --level best
ziplark create secret.7z ./folder --password hunter2

Mac の 7-Zip — よくある質問

macOS 向けの公式な 7-Zip はありますか？

いいえ — あるのは p7zip コマンドライン移植版だけです。Ziplark は、macOS 上で GUI から .7z を開いて作成できる無料・オープンソースのアプリです。

Mac で .7z ファイルを展開するにはどうすればよいですか？

Ziplark をインストールし、.7z をダブルクリックするかウィンドウにドラッグして、 展開先を選びます。

暗号化された 7z アーカイブを作成できますか？

はい — Ziplark はすべての OS で AES-256 暗号化された .7z（および ZIP）アーカイブを作成します。

Apple Silicon で動作しますか？

はい。macOS ビルドはユニバーサルで、Apple Silicon と Intel 向けに公証済みです。
