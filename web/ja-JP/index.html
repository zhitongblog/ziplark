Ziplark が選ばれる理由

🪶

小さく、速い

サイズを最適化したリリースビルド — LTO、シンボル削除、panic=abort。 デスクトップアプリは OS のウェブビューを利用するため、Chromium を同梱しません。

🛡️

設計から安全

すべての展開処理は、単一の zip-slip ガードを通過します。細工された ZIP、RAR、tar であっても、 どのエントリも展開先フォルダーの外に出ることはできません。

⚙️

ひとつのエンジン、3 つの方法

GUI、CLI、MCP サーバーは、ひとつの Rust コアを包む薄いシェルです。 アプリでできることは CLI でもまったく同じにでき、スクリプトからも扱えます。

📦

あらゆる一般的な形式

ZIP、RAR（RAR5 や暗号化を含む）、7z、tar と圧縮 tar の各種、 単一ストリームの gz/bz2/xz/zst/lz4 — そして ISO 9660 ディスクイメージ。

対応形式

形式展開作成暗号化
ZIP✓✓AES-256（ZipCrypto の読み込み対応）
7z✓✓AES-256
RAR / RAR5✓—暗号化の読み込み対応
tar✓✓—
tar.gz / .bz2 / .xz / .zst / .lz4✓✓—
gz / bz2 / xz / zst / lz4（単一ストリーム）✓✓—
ISO 9660 / Joliet（ディスクイメージ）✓——

RAR の作成は意図的に非対応です — RAR の圧縮形式は独自仕様のためです。 展開（RAR5 や暗号化アーカイブを含む）は完全に動作します。

ターミナルやエージェントのためにも

CLI — ziplark

あらゆるアーカイブの一覧表示、展開、作成、検証ができます。すべてのコマンドに --json を用意し、スクリプト化も簡単です。

ziplark list  movie.rar
ziplark extract photos.zip -o ./out
ziplark create backup.tar.zst ./src --level best
ziplark create secret.zip ./private --password hunter2
ziplark test  download.7z

MCP サーバー — ziplark-mcp

Model Context Protocol を通じて、あらゆる LLM から Ziplark を操作できます。読み取りツールは 常に有効で、書き込みは --allow-write で制限されます。

{
  "mcpServers": {
    "ziplark": {
      "command": "ziplark-mcp",
      "args": ["--allow-write"]
    }
  }
}

よくある質問

Ziplark は無料ですか？

はい — MIT ライセンスの無料・オープンソースで、広告もテレメトリもありません。

Ziplark で RAR ファイルを開けますか？

はい。Ziplark はパスワード保護されたものを含め、RAR および RAR5 アーカイブを展開できます。 RAR アーカイブの作成はできません — この形式は独自仕様のためです — が、 読み込みは完全に対応しています。

macOS、Windows、Linux で動作しますか？

3 つすべてに対応しています。macOS はユニバーサルの公証済みビルド、Windows は .msi/.exe、Linux は .deb と AppImage で提供します。

WinRAR、7-Zip、The Unarchiver の優れた無料代替になりますか？

はい。Ziplark はクロスプラットフォームで、無料かつ極小です。ZIP、RAR、7z、tar を読み込み、 ZIP（AES-256）、7z、tar を作成できます — さらにスクリプト化や自動化のための CLI と MCP サーバーも同梱しています。ガイド： 無料の WinRAR 代替、 Mac で RAR を開く、 Mac 向け 7-Zip。

暗号化・パスワード保護されたアーカイブに対応していますか？

はい。AES-256 で暗号化した ZIP と 7z アーカイブを作成し、暗号化された RAR と 7z アーカイブを読み込めます。

コマンドラインやスクリプトから使えますか？

はい — ziplark CLI はアプリと同じことをすべて行え、すべてのコマンドに --json を備えています。さらに ziplark-mcp が、Model Context Protocol を通じてあらゆる LLM に機能を公開します。
